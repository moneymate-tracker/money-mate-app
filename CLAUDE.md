# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

All commands run from the `client/` directory.

```bash
npm start           # Start Expo dev server (opens Expo Go QR)
npm run android     # Run on Android emulator/device
npm run ios         # Run on iOS simulator (macOS only)
npm run web         # Run in browser
```

For physical device testing, use Expo Go app and scan the QR code from `npm start`. For custom native code, use `expo run:android` or `expo run:ios` (requires native build toolchain).

There is no test suite configured. Lint is not configured either.

## Architecture

### Stack
- **React Native + Expo 55** (SDK 54) — managed workflow with `expo-dev-client` for native modules
- **NativeWind 2.x** — Tailwind CSS for React Native via `className` prop (configured in `tailwind.config.js`)
- **React Navigation 7** — bottom tabs + stack navigator
- **Redux Toolkit** — auth state only; all other state is local or via dummy data
- **Axios** — HTTP client with interceptor that auto-attaches Bearer token

### Navigation flow (`navigation/AppNavigator.js`)
1. Redux `isFirstLaunch` flag → routes new users to `Welcome` → `Login`/`SignUp`
2. Authenticated users land on a bottom tab navigator: **Home, Expenses, Add, Budget, Profile**
3. The "Add" tab button is a custom FAB (gradient circle, rendered via `tabBarButton`)
4. Modal/stack screens (Analytics, ExpenseList, EditProfile, etc.) sit outside the tab navigator

### Auth (`services/auth.service.js` + `redux/slices/auth.slice.js`)
- API base URL is **hardcoded**: `http://192.168.29.240:8000/api/v1/auth` — change this for your environment
- Tokens (`accessToken`, `refreshToken`) are persisted in `AsyncStorage` with an in-memory fallback
- The Axios instance adds `Authorization: Bearer <token>` via a request interceptor
- Redux thunks: `signup`, `login`, `logout`, `checkAuthStatus`

### Theme (`theme/ThemeContext.js`)
- Wraps the entire app via `ThemeProvider` in `App.js`
- Consume with `useTheme()` hook — returns `{ isDarkMode, toggleDarkMode, colors, background, card, text, textMuted, border, ... }`
- Auto-detects system color scheme; manual toggle is available
- Primary brand color: `#6C63FF` (purple); accent: orange

### Data
- All screen data currently comes from `data/dummyData.js` (mock expenses, categories, user profile)
- Backend integration is incomplete — screens use local mock helpers like `getExpensesByMonth()`

## Key Patterns

- **Styling**: Use `className` (NativeWind/Tailwind) for layout and spacing; use inline `style` only for dynamic values (e.g., themed colors from `useTheme()`). Custom Tailwind colors are defined under `primary` and `dark` keys.
- **Icons**: `@expo/vector-icons` (Ionicons, MaterialCommunityIcons) — no custom icon system
- **Charts**: `react-native-gifted-charts` for bar/line charts on HomeScreen and AnalyticsScreen
- **Gradients**: `expo-linear-gradient` used for the FAB button and decorative accents
